# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability affecting NOVLIRI or this repository, please report it privately rather than opening a public GitHub issue.

Email: security@novliri.com

Please include, when possible:

- A description of the vulnerability and its potential impact
- The affected page, file, or component
- Steps to reproduce the issue
- Any proof-of-concept details that can be shared safely
- Suggested remediation, if known

Please avoid accessing, modifying, or deleting data that does not belong to you, disrupting the service, or publicly disclosing an unresolved vulnerability.

We will review good-faith reports and work to address confirmed security issues as appropriate.

## Scope

This policy covers the NOVLIRI website and code maintained in this repository. Third-party websites and services linked from NOVLIRI are outside NOVLIRI's security scope and should be reported to their respective operators.
